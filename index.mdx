# Instructor

Define a Pydantic model. Pass it to Claude, GPT, Gemini, or any of 15+ supported providers. Get back a validated Python object.

```python
import instructor
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

client = instructor.from_provider("openai/gpt-4.1-mini")

user = client.create(
    response_model=User,
    messages=[{"role": "user", "content": "Ada Lovelace, born 1815, was 36 when she died."}],
)

print(user)
# User(name='Ada Lovelace', age=36)
```

No JSON parsing. No regex. No retry loops. Validation, retries, and streaming are built in.

## Who this is for

Python developers building applications that need structured data from LLMs. You should be comfortable with Pydantic models and async Python.

## What Instructor handles

Schema enforcement turns your Pydantic model into a JSON schema the model can target. Automatic retries catch validation errors and feed them back so the model can self-correct. Streaming yields partial models as fields fill in, useful for progressive UI updates. Provider abstraction lets you swap OpenAI for Anthropic by changing one string.

If you've been parsing LLM JSON by hand, regex-matching responses, or wrapping calls in retry loops, Instructor replaces all of that.

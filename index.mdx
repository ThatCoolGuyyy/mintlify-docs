# Instructor

Instructor turns any LLM into a typed function. Define a Pydantic model, pass it to the client, and get back a validated Python object instead of a raw string.

It works with OpenAI, Anthropic, Google, Mistral, Cohere, Ollama, and 15+ other providers using the same interface. Validation, retries, and streaming are built in.

```python
import instructor
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

client = instructor.from_provider("openai/gpt-4.1-mini")

user = client.create(
    response_model=User,
    messages=[{"role": "user", "content": "Ada Lovelace, born 1815, was 36 when she died."}],
)

print(user)
# User(name='Ada Lovelace', age=36)
```

## Who this is for

This site is for Python developers building applications that need structured data from LLMs. You should be comfortable with Pydantic models and async Python. Familiarity with at least one LLM provider's SDK helps but isn't required.

## What Instructor handles for you

Instructor wraps your LLM client and adds four things on top of the raw provider SDK.

Schema enforcement turns your Pydantic model into a JSON schema the model can target. Automatic retries catch validation errors and feed them back to the model with context so it can self-correct. Streaming support lets you yield partial models as fields fill in, useful for showing progressive UI updates. Provider abstraction means you can swap OpenAI for Anthropic by changing one string.

If you've been parsing LLM JSON output by hand, regex-matching responses, or wrapping calls in try/except blocks that retry on bad output, Instructor replaces all of that.
